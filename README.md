# Activity Management System

Web-based system for managing local store operations including inventory, sales, and purchasing.

## Overview

| Attribute | Details |
|-----------|---------|
| Type | PHP Web Application |
| Framework | PHP + MySQL + Bootstrap + AJAX |
| License | MIT |

## Features

- Product Management - Catalog and inventory
- Sales Tracking - Transaction recording
- Inventory Management - Stock control
- Order Processing - Purchase orders
- Customer Management - Client database
- Supplier Management - Vendor relationships
- Purchasing - Buy from suppliers
- Reporting - Business reports

## Tech Stack

- Backend: PHP
- Database: MySQL
- Frontend: Bootstrap
- AJAX: Asynchronous operations

## Project Structure

`

## Getting Started

### Prerequisites

- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx

### Installation

1. Clone the repository
2. Setup database
3. Configure connection
4. Start server
